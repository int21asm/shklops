# Saved feature ideas

## Sankey income and expenses chart — deferred on 2026-10-22

The user asked to save this idea for later, while prioritizing the recurring-payments panel.

- A full-width dashboard panel, **לאן הכסף זורם?**, with a month selector.
- Income from actual bank credits flows to bank expenses, mortgage, credit-card payments, and the remaining balance or deficit.
- Credit-card payments expand into their saved merchant categories.
- Ribbon widths represent amounts; hover shows the amount, percentage and contributing transactions. Categories can be clicked to inspect activity.
- Use Hebrew RTL labels and Shklops colors; SVG is sufficient for rendering.
- Count each card settlement once. Categorized card transactions explain that settlement and must not be added again as expenses. Unmatched amounts must be explicit rather than inventing a reconciled breakdown.
